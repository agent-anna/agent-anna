# FOMO TRADING BOT // KNOWLEDGE BASE

## System Overview
Semi-automated trading system following top traders on FOMO.family using Grok Bot as control interface.

## Setup Checklist

| # | Action | Expected Result |
|---|--------|-----------------|
| 1 | Create trading account via FOMO referral link | Your FOMO home |
| 2 | Create 2nd FOMO account via same referral link | Empty bot account |
| 3 | Create Telegram bot via @BotFather | Bot token received |
| 4 | Log empty account into Grok Bot browser | Vault saves session |
| 5 | Paste Copy Bot prompt + bot token | Proof of setup |
| 6 | Send /start to Telegram bot | Menu displayed |
| 7 | Navigate to Accounts → Import top 30 | Traders imported |
| 8 | Configure Filters | Values persist |
| 9 | Run first poll | Old trades marked seen |
| 10 | Trade card appears → tap Copy | Trade card captured |

## Trader Selection
- Skip 24h board (1 lucky coin noise)
- Use 7d list for current hot traders
- Use 30d list for sustained performance
- Best: Import traders on BOTH lists
- Min trade count filter to reduce noise

## Bot Token
Store securely. Never share. Rotate if compromised.

## Emergency
FOMO has no public API. Using app's unofficial API — may break without notice.
