# FOMO Trading Bot System Specification

## Overview
A semi-automated trading system that follows top traders on FOMO.family using Grok Bot as the control interface.

---

## Setup Checklist

| # | Action | Expected Result |
|---|--------|-----------------|
| 1 | Create trading account via [FOMO](https://fomo.family/r/savipww) | Your FOMO home |
| 2 | Create a 2nd FOMO account using the same referral link (the code only sticks at signup) | Empty account for bot access |
| 3 | Create a Telegram bot via `@BotFather` and paste its token only into Grok Bot | Bot token received |
| 4 | Log the empty account into Grok Bot's browser, then Vault saves the session | Grok Bot reads the login token, or prompts you to paste it once per hour (path B below) |
| 5 | Paste the Copy Bot prompt + bot token | Proof of each completed step |
| 6 | Send `/start` to the Telegram bot | Menu displayed |
| 7 | Navigate to Accounts → Import top 30 → select both (7d and 30d) | Traders imported with Profile data |
| 8 | Configure Filters: min trades, market cap, liquidity | Values persist |
| 9 | Run first poll | Silent; old trades marked as seen |
| 10 | When a trade card appears, tap Copy to buy on FOMO | Trade card captured |

---

## Trader Selection Guidelines

- **Skip 24h board**: A single day's PnL is often due to 1 lucky coin.
- **Use 7d list**: Shows who is currently hot.
- **Use 30d list**: Shows who sustains performance.
- **Best approach**: Import traders appearing on *both* lists.
- Set a minimum trade count filter to reduce noise.
